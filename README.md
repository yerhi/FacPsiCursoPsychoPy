Material for the Introduction to PsychoPy workshop. UNAM 2019.
The PsychoPyIntro 2019 file includes the slides used during the introduction.
The minimalistFaruk.py file is an example script to get acquainted with what PyshcoPy can do and how (eg. visual stimuli, duration, conditional statements).
The GoNoGo.py file is the script for the GoNoGo task used in the Sexual Inhibition study at Maastricht University in 2018-2019. This is also a good example on how to use conditional statements and loops, which results very useful to record and codify the response of participants.
